# Haushaltsbuch

Gemeinsames Haushaltsbuch mit Sparzielen – als installierbare Web-App fürs Handy.

- Daten liegen in Firebase (Firestore) und sind durch `firestore.rules` geschützt.
- `app.js` ist das gebündelte Programm, der Quelltext liegt in `src/`.
- Zugangsdaten stehen in `firebase-config.js` (nicht geheim).
